# Integração do template Cruip Open React

A página inicial agora usa como base o template [Cruip Open React](https://github.com/cruip/open-react-template), adaptado para o conteúdo e a identidade da Gama Galvão Engenharia.

## Arquivos de origem incorporados

- `src/app/css/style.css`
- `src/app/css/additional-styles/theme.css`
- `src/app/css/additional-styles/utility-patterns.css`
- Tipografia Nacelle em `public/fonts/`
- Estrutura visual de `Spotlight`, usada nos cartões de áreas de atuação

As páginas, imagens, textos, rotas, navegação e dados de obras pertencem ao site da Gama Galvão. Componentes do template foram adaptados e componentes de autenticação, depoimentos fictícios, vídeo promocional e conteúdo de SaaS foram deixados de fora.

O README do repositório Cruip declara que o template é disponibilizado sob GPL. Consulte o repositório original para os termos aplicáveis ao template e a redistribuições modificadas.
